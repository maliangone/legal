SafeGuard Family Privacy Policy

Last updated: July 2026

1. Information We Collect

SafeGuard Family collects the following information to provide parental monitoring services:

  • Account information — email address, password hash
  • Device information — device name, model, OS version
  • Location data — GPS coordinates, collected at configurable intervals
  • App usage data — installed apps, usage duration
  • Browser history — URLs visited in SafeGuard Browser
  • Screen time data — daily usage, active/idle periods

All data is collected with parental consent and is used solely for the purpose of child safety monitoring.

2. How We Use Your Information

We use collected information to:

  • Display child device activity to the parent dashboard
  • Enforce parental controls (app whitelisting, URL filtering, screen time limits)
  • Send notifications and alerts (geo-fence, SOS, screen time)
  • Generate weekly activity reports
  • Improve our services and fix technical issues

3. Data Storage & Security

  • All data is stored in Google Firebase (Firestore, Storage) with encryption in transit (TLS)
  • PIN codes are hashed using bcrypt and stored in device secure storage
  • Firestore security rules enforce per-family data isolation
  • We do not sell, share, or transfer personal data to third parties

4. Data Retention

  • Account data — retained until account deletion
  • Location events — retained for 90 days, then automatically purged
  • Activity logs — retained for 90 days
  • You may request deletion of all data by contacting support

5. Accessibility Service Usage

SafeGuard's child app uses Android's AccessibilityService as an optional enhancement to improve the speed of parental control enforcement. This service:

  • Detects when apps outside the parent-approved whitelist are opened on the child's device
  • Returns the child to the SafeGuard launcher immediately when a blocked app is detected
  • Does NOT collect, store, or transmit any accessibility data
  • Does NOT read screen content, passwords, or personal information
  • Does NOT interact with UI elements or monitor user input
  • Does NOT perform any action without explicit parent configuration of app rules

The AccessibilityService is optional. You can disable it at any time in Android Settings → Accessibility → SafeGuard. The app will continue to enforce parental controls with slightly slower blocking response time using its primary enforcement mechanism (SYSTEM_ALERT_WINDOW + UsageStatsManager).

Technical scope: SafeGuard only listens to TYPE_WINDOW_STATE_CHANGED events (app window switches) and has canRetrieveWindowContent set to false. No on-screen content is ever accessed.

6. Children's Privacy (COPPA)

SafeGuard Family is designed for use by parents to monitor children under 13. We comply with the Children's Online Privacy Protection Act (COPPA):

  • The child app does not collect personal information directly from children
  • All monitoring is initiated and controlled by the parent
  • Parents may review, delete, or stop collection of their child's data at any time
  • No advertising or tracking SDKs are present in the child app

7. Singapore PDPA Compliance

For users in Singapore, we comply with the Personal Data Protection Act (PDPA):

  • We collect personal data only with consent and for stated purposes
  • Data is protected with reasonable security arrangements
  • You may access, correct, or withdraw consent for your personal data

8. GDPR Compliance (EU/EEA)

For users in the European Union and European Economic Area, we comply with the General Data Protection Regulation (GDPR):

  • Right to rectification — You may request correction of inaccurate personal data
  • Right to erasure — You may request deletion of your personal data ("right to be forgotten")
  • Right to data portability — You may request your data in a structured, machine-readable format
  • Right to object — You may object to the processing of your personal data
  • Right to restrict processing — You may request that we limit our processing of your data
  • Data Protection Officer — Contact us at info@shenbee.com
